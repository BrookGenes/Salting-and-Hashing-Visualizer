Password Salting and Hashing Visualizer: This project demonstrates how password hashing and salting work using Python's SHA-256 hashing function.

How to run it: Open the notebook in Google Colab and run the code cell.

Example output:
- A normal hash is generated for each test password.
- A salted hash is generated using a random salt.

Using different salts produces different hashes for the same password.

REFLECTION: This project helped me understand how hashing and salting protect passwords. The hardest part was understanding how adding a salt changes the hash, but the examples made it easier to see. In the future, I would add a visual display to make the process easier to understand.
